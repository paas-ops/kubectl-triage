# v0.3.0 — M3 Beta 分发

第三个里程碑版本：把"装得上、看得懂、放心用"补齐——预编译产物、校验与签名、SBOM、容器镜像、
文档站与 opt-in 遥测。**默认行为不变：离线、只读、零网络**。

## 安装

```bash
# 源码（任何版本）
go install github.com/paas-ops/kubectl-triage/cmd/kubectl-triage@v0.3.0

# 预编译二进制：从本 Release 下载对应平台 tar.gz
# Docker
docker run --rm ghcr.io/paas-ops/kubectl-triage:v0.3.0 version
# Homebrew（formula 在本 Release 资产中；tap 见 docs/homebrew.md）
```

## 本版本新增

- **预编译产物**：darwin/linux × amd64/arm64 四个平台 tar.gz + `checksums.txt`（sha256）。
- **供应链**：cosign keyless 签名（`checksums.txt.sig` / `.pem`，也可对镜像 digest 验签）；
  每个归档附 CycloneDX SBOM（`*.cdx.json`）。
- **容器镜像**：`ghcr.io/paas-ops/kubectl-triage:v0.3.0` 与 `:latest`，distroless、nonroot、
  按 digest 签名。
- **Homebrew**：生成 `kubectl-triage.rb` formula 作为 Release 资产；tap 自动推送需要
  `HOMEBREW_TAP_GITHUB_TOKEN`（见 docs/homebrew.md）。
- **文档站**：https://paas-ops.github.io/kubectl-triage/ （静态、无外部依赖、可离线打开），
  以及 install / homebrew / quickstart / security / pilot 文档与试点申请 issue 模板。
- **opt-in 遥测**：默认关闭；`telemetry status|enable|disable`；仅上报 10 个白名单字段，
  绝不采集事故内容/集群/命名空间/日志/路径/密钥；2s 有界、失败静默、不阻塞分析。
- **CI**：新增 `release-check`（goreleaser check）与 `docker-build` 冒烟；既有 test 与
  darwin/linux × amd64/arm64 交叉编译矩阵保留。

## 校验方式

```bash
sha256sum -c checksums.txt            # macOS: shasum -a 256 -c checksums.txt
cosign verify-blob --certificate checksums.txt.pem --signature checksums.txt.sig checksums.txt
cosign verify --certificate-identity-regexp 'https://github.com/paas-ops/kubectl-triage/.github/workflows/release.yml@refs/tags/v.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  ghcr.io/paas-ops/kubectl-triage:v0.3.0
```

详见 [docs/install.md](https://github.com/paas-ops/kubectl-triage/blob/main/docs/install.md)。

## 已知限制

- Homebrew tap（`paas-ops/homebrew-tap`）的自动推送需要独立 PAT；formula 资产已提供。
- 遥测仅定义客户端与字段契约，官方统计端点未随本版本提供（未配置端点时事件丢弃）。
- 模型模式仍需用户自备 key 或本地 Ollama（沿用 v0.2.0 行为）。
- 本版本为 v0.x Beta；正式评测前不应作为生产决策唯一依据；企业 `push`（M4）尚未实现。
