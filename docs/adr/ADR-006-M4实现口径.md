# ADR-006：M4 企业桥（push 客户端与公开协议）

| 项 | 内容 |
| --- | --- |
| 状态 | 已接受（Accepted） |
| 日期 | 2026-10-30 |
| 关联 | [需求文档](../需求文档.md) §2.1/§3/§6/§12、[拆分计划](../拆分计划.md) §4 Epic G、[ADR-002](ADR-002-契约口径.md)–[ADR-005](ADR-005-M3实现口径.md) |
| 目的 | 冻结 OSS 仓库内唯一的企业桥能力：`push` 客户端与公开协议 |

## 背景

拆分计划把企业桥限定在 OSS 仓库只保留 **push 客户端 + 公开协议**；企业事故库、去重、评测集
上传、审计、私有部署（G2–G5）在商业版 CloudOps Agent 侧实现，不进入本仓库。需求 §12 待决
第 4 项（"只同步报告/证据哈希，还是可选同步脱敏证据包"）在此定稿：**默认只同步报告与证据哈希；
脱敏证据包必须显式 `--include-evidence` 才上传。**

## 决策

### D1 配置与显式性

- 推送是**唯一**除模型外会主动联网的命令，且**必须显式配置**才可能执行：
  - 端点：`--endpoint` 或环境变量 `KUBECTL_TRIAGE_ENTERPRISE_ENDPOINT`；
  - 令牌：仅环境变量 `KUBECTL_TRIAGE_ENTERPRISE_TOKEN`（不接受 flag，不写入报告/日志/错误信息）。
- 端点缺失或令牌缺失 → 退出码 1（配置错误），不发起任何网络请求。
- 端点必须是 `https`；仅允许 `http` 用于 loopback（`127.0.0.1` / `localhost` / `::1`）本地联调。

### D2 请求协议（protocol_version 1.0）

`POST {endpoint}/v1/push`，请求头：

```text
Authorization: Bearer <token>
Content-Type: application/json
Idempotency-Key: <push_id>
User-Agent: kubectl-triage/<cli-version>
```

请求体：

```json
{
  "protocol_version": "1.0",
  "push_id": "uuid-v4（同一次推送的重试保持不变）",
  "created_at": "RFC3339",
  "cli": { "version": "...", "rules": "...", "model": "..." },
  "report": { "schema_version": "1.0", "...": "完整 report.json" },
  "report_sha256": "sha256:<hex>",
  "evidence": [
    { "id": "ev-001", "source": "k8s.events", "content_ref": "k8s/events.json#items/0", "sha256": "sha256:<hex>" }
  ],
  "bundle": { "included": false }
}
```

`--include-evidence` 时 `bundle` 为：

```json
{
  "included": true,
  "content_type": "application/gzip",
  "sha256": "sha256:<hex>",
  "size_bytes": 12345,
  "content_base64": "..."
}
```

- 证据包内容：`incident.yaml` + 事故包文本证据（确定性 tar.gz 顺序，排除 `report.*`、
  `.git`）；已经是脱敏后的输入。
- 默认（不带 flag）只发报告与证据哈希，**不上传证据正文**。

### D3 响应与错误

成功（2xx）：

```json
{ "accepted": true, "protocol_version": "1.0", "incident_id": "..." }
```

失败（4xx）：

```json
{ "error": { "code": "auth_failed|invalid_payload|duplicate|...", "message": "..." } }
```

客户端映射：

| 情形 | 退出码 |
| --- | --- |
| 2xx accepted | 0 |
| 4xx（含 400/401/403/409/422） | 1（配置/鉴权/被拒绝） |
| 网络错误、超时、429、5xx（重试耗尽） | 3 |
| 推送前安全校验失败（报告含凭据模式等） | 4 |

- 重试：网络错误/429/5xx 最多重试 2 次（退避 500ms/1s），总共受 `--timeout`（默认 30s）约束；
  4xx 不重试；重试复用同一 `push_id` + `Idempotency-Key`。
- HTTP 客户端禁用重定向；TLS 校验不可关闭。

### D4 幂等与版本

- `push_id` 为 UUID v4，同一命令内重试不变；服务端按 `Idempotency-Key` 去重（重复推送返回
  2xx 或 409 由服务端决定，客户端两种都视为"未失败"，但 409 仍退出 1 并提示）。
- `protocol_version` 固定 `1.0`；服务端必须拒绝未知主版本；新增字段保持向后兼容。
- 报告中记录 `cli.version/rules/model`，便于企业侧审计。

### D5 安全边界

- 推送前执行 `bundle.Load` + `bundle.Validate`（strict 脱敏模式）：不通过 → 1 / 4。
- 推送前对报告 JSON 做敏感模式扫描（复用 `internal/redact`）：命中 → 退出 4，不发送。
- 令牌只从环境变量读，错误信息与 `--dry-run` 输出均不回显令牌；payload 不含绝对路径。
- `--dry-run`：构建 payload 并输出摘要（protocol_version、report_sha256、evidence_count、
  bundle 是否包含与大小），不联网、退出 0；可配合 `--out` 落盘 JSON 便于审计/联调。

### D6 与 OSS/企业版边界

- OSS 只提供客户端与本文档；协议对服务端实现是公开契约。
- 企业版（CloudOps Agent）实现：`/v1/push` 接收、事故库导入/去重、评测集上传/版本对比、
  审计事件、私有部署；这些**不进入**本仓库。
- 推送失败不影响本地报告：报告已落盘，push 只读报告与证据包。

### D7 版本与发布

- M4 发布 `v0.4.0`（tag 触发既有 release workflow，含产物自校验）。
- 试点运营材料（资格、28 天流程、验收口径、指标漏斗）在 `docs/pilot-playbook.md` 与
  `docs/metrics.md` 维护；申请入口沿用 `.github/ISSUE_TEMPLATE/pilot-request.yml`。

### D9 实现澄清（v0.4.0，文档以实现为准）

- `--max-bundle-bytes` 默认 **5 MiB（5242880）**，按压缩后 tar.gz 大小判定；超限 → 配置错误、
  退出 1、不联网。
- `--timeout` 默认 **30s**，是整体预算（打包 + 重试）；预算耗尽立即停止并退出 3。
- 重试：首次 + 最多 2 次（共 3 次尝试），固定 500ms/1s 退避，无 jitter，不处理 `Retry-After`；
  可重试 = 网络错误 / 429 / 5xx / 2xx 响应体非法；3xx 由禁用重定向拒绝 → 按网络错误重试后退出 3。
- 2xx 响应必须 `accepted: true`；缺 `protocol_version` 时客户端回退 payload 的 `1.0`；
  响应体读取上限 1 MiB。
- `--out`：payload JSON（indent 2 + 末尾换行、0644、不含 token），`--dry-run` 与正式推送均可用；
  正式推送在发送前落盘（失败仍保留，便于审计）。
- `--dry-run` 输出中文文本摘要（端点/协议版本/push_id/created_at/report_sha256/证据条数/
  bundle 是否包含及大小）；仍要求端点 + 令牌已配置（仅本地校验，不联网）。
- `report_sha256` 口径：把 report.json 解码为 `report.Report` 后紧凑序列化（nil 切片→`[]`、
  map 键排序），哈希对这段紧凑字节；服务端应按请求中 `report` 成员**原始字节**验算。
- `User-Agent = kubectl-triage/<report.versions.cli>`；`push_id` 为小写 UUID v4。
- bundle 确定性：文本扩展名 `.yaml/.yml/.json/.log/.txt/.md` + `incident.yaml`；POSIX 相对路径
  排序；排除 `report.*` / `.git` / `node_modules`；tar mode 0644、mtime `Unix(0,0) UTC`、
  uid/gid 0、Uname/Gname 空、TypeReg；gzip 使用 Go 默认头。
- 端点 URL：拒绝 userinfo/query/fragment；保留 base path（`{endpoint}/v1/push`）；仅
  `127.0.0.1` / `localhost` / `::1` 允许 http；令牌仅从环境变量读取。
